# Changelog

## v1.0.0

First public GitHub release of ND Pico2DMX Node.

- Four independent DMX outputs
- Art-Net and sACN input over Ethernet and Wi-Fi
- Browser dashboard with status, configuration, testing, and update controls
- Hardware-validated RP2350 and ESP32-C5 production baseline
- Ethernet OTA validation completed from F4 to F5 on real hardware

Validated firmware:

- RP2350 main controller: `V3.6F5-RP2350`
- ESP32-C5 Wi-Fi controller: `V3.6A-C5`
