# Historical bring-up tests

These projects were used while developing and validating the hardware. They are kept for reference and troubleshooting. They are not required to operate or build the current production firmware.

The UART RP2350 ↔ ESP32-C5 projects are historical experiments. UART is **not** the current production interprocessor transport. Current production transport is SPI.

The SPI isolation projects document the later production-link bring-up work. None of the projects in this directory should be presented as the current production architecture.
