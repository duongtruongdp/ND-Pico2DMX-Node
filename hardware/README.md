# Hardware reference

## Current production hardware

- Main controller: Waveshare W5500-EVB-Pico2 / RP2350
- Wi-Fi controller: ESP32-C5 DevKit V2.0 / XH-C5E_V2.0
- Module: ESP32-C5-N16R8
- Outputs: four independent DMX outputs

The four-output hardware is the current production configuration.

An eight-output expansion is possible as a future architecture, but it is not a current feature of this repository.
